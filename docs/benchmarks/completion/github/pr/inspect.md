조회·입력 작성·저장·복구·편집·최종 확인과 오류/재시도는 전부 포함한다. 직접 처리에도 필터·배치·한 스크립트의 저장/read-back을 허용한다. 실제 파일 I/O syscall 수는 계측하지 않았으며 CLI 수와 혼동하지 않는다. 보고서 저장·재확인에 따른 추가 I/O와 호출은 부분 개선의 부담이다.
