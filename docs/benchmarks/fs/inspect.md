연결 실행 예제를 설치해 둔 환경의 비교입니다. Python 예제는 실제 inspect·apply를 실행하며 두 CLI 호출 모두 집계합니다. 예제의 최초 설치·발견 비용은 측정하지 않았습니다. 직접 처리에는 한 스크립트도 허용하며 이 결과를 일반적인 파일 편집 전체로 확대하지 않습니다.

원문·필요한 검증을 제거하거나 반복 사용·모델 캐시 적중을 절감의 전제로 삼지 않았습니다. 새 세션은 입력 캐시 없는 실행의 증명이 아닙니다. 평균·범위와 전체 불리한 기록을 함께 확인합니다.
