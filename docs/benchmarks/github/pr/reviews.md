# `tools github pr reviews` 벤치마크

[경로를 모르는 리뷰·긴 로컬 원문의 최신 완료 비교](../../completion/github/pr/reviews.md). 아래의 기존 일반 시나리오와 입력·완료 범위가 다르므로 절감률을 합산하지 않는다. 원본은 해당 코호트에 보존한다.

[공통 조건·전체 기록·재현](../../usage/README.md). 가장 최근의 해당 작업만 표시하며 이전의 다른 요구 범위와 비교하지 않습니다.
