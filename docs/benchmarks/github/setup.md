# github setup

`tools github setup --json`과 직접 `gh api`를 이용한 설정 저장을 비교했습니다. 카탈로그를 조회해 11개 prefix의 기존 라벨·활성 이슈 유형 매핑과 한국어 본문 정책을 `.tools.json`에 저장했습니다. 직접 방식은 같은 후보 우선순위로 매핑을 선택하고 파일을 작성합니다. 기존 설정이 없는 첫 설정 작업이며 라벨·유형은 새로 만들지 않습니다.

2026-10-07, `gpt-6.1-sol`, high 추론, 방식별 새 세션 3회입니다. 실제 `gh`·Git·프로덕션 CLI와 로컬 실험 API를 사용했습니다. 토큰은 캐시 입력을 포함한 에이전트 작업 전체의 값입니다.

| 평균 또는 범위 | 직접 `gh` | `tools` |
|---|---:|---:|
| 총 토큰 | 53,970 | 30,473 |
| 캐시 제외 입력 | 17,093 | 15,535 |
| 캐시 입력 | 35,925 | 14,720 |
| 출력 토큰 | 952 | 218 |
| 쉘 명령 항목 | 4 | 1 |
| 실행 시간(초) | 35.02 | 12.55 |
| 총 토큰 범위 | 47,773–66,156 | 30,416–30,556 |

총 토큰 차이는 −43.5%, 캐시 제외 입력은 9.1% 적었습니다. 비교한 6회 모두 반환 JSON과 독립적인 최종 상태 검증을 통과했습니다. 저장 파일 전체가 기준과 일치했고 Git 참조·설정·worktree·작성 파일을 보존했습니다.

최초 직접 처리 3회는 `python` 명령 부재에 따른 재시도 비용이 있어 원본에 보존하고 비교에서 제외했습니다. 명령 이름 `python3`를 명시한 직접 처리 3회를 다시 측정하고 기존 `tools` 결과와 비교했습니다. 기존 매핑 보존·`--refresh`·동시 파일 변경은 측정하지 않았습니다.
