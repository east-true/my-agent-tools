# 리뷰 추출

`scripts/benchmarks/github_candidates.py reviews`를 측정한 오프라인 프로토타입입니다. 실제 `tools github` 하위 명령으로 구현된 기능은 아닙니다.

2026-10-07에 고정된 공개 GitHub 응답을 사용해 `gpt-6.1-sol`, high 추론, 방식별 새 세션 3회로 비교했습니다. 평균 총 토큰은 직접 `gh` 31,379, 후보 30,994로 1.2% 적었으며, 비교한 6회 모두 기준 정답과 일치했습니다.

최적화된 `gh --jq`와 프로토타입의 출력은 바이트 단위로 같았습니다. 안내·명령 텍스트·모델 출력 변동이 포함되므로 내용 필터링 자체의 고유한 절감 효과는 입증하지 못했습니다.

[공유 후보 원본 JSON](candidates.json)의 `summary.reviews`에 결과가 있으며, 프롬프트·응답·검증·한계도 함께 보존합니다. 내부 코드만 실행한 추가 검증은 [CI 후속 측정](ci.md#내부-파서-후속-측정)에 있습니다.
