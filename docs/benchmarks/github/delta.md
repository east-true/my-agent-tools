# PR 증분 조회

`scripts/benchmarks/github_candidates.py delta`를 측정한 오프라인 프로토타입입니다. 실제 `tools github` 하위 명령으로 구현된 기능은 아닙니다.

2026-10-07에 고정된 공개 GitHub 응답을 사용해 `gpt-6.1-sol`, high 추론, 방식별 새 세션 3회로 비교했습니다. 평균 총 토큰은 직접 `gh` 32,981, 후보 33,968로 3.0% 증가했으며, 비교한 6회 모두 기준 정답과 일치했습니다.

직접 처리의 한 실행은 `gh --jq`로 요청한 메타데이터만 반환했지만 후보는 patch도 포함했습니다. 허용된 최적화 결과를 제외하지 않고 유지했습니다. 이 비교에서는 토큰 절감이 없었습니다.

[공유 후보 원본 JSON](candidates.json)의 `summary.delta`에 결과가 있으며, 프롬프트·응답·검증·한계도 함께 보존합니다. 내부 코드만 실행한 추가 검증은 [CI 후속 측정](ci.md#내부-파서-후속-측정)에 있습니다.
