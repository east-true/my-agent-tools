# github context

`tools github context --json`과 직접 `gh api`의 독립적인 저장소·라벨·이슈 유형 조회를 비교했습니다. 저장소 이름, 기본 브랜치, 라벨 11개와 활성 이슈 유형 3개를 반환하며, 비활성 유형 1개를 선택 목록에서 제외합니다.

2026-10-07, `gpt-6.1-sol`, high 추론, 방식별 새 세션 3회입니다. 실제 `gh`, 프로덕션 CLI의 API 의존성 주입, 로컬 실험 API를 사용했습니다. 양쪽에 사용 안내를 제공하고 직접 처리의 명령 묶음과 필터를 허용했습니다.

|---|---:|---:|
| 총 토큰 | 30,221 | 29,894 |

| 캐시 입력 | 9,728 | 9,643 |

총 토큰 차이는 −1.1%이고 캐시 제외 입력은 0.6% 적었습니다. 6회 모두 독립 기준과 일치했고 Git 참조·설정·worktree·작성 파일과 API 상태를 보존했습니다. 큰 토큰 절감은 관찰되지 않았습니다.

캐시는 통제하지 않았으며 작은 고정 실험입니다. 금액 절감이나 실제 GitHub 서버 지연을 나타내지 않습니다. [공통 조건과 재현](command-suite.md), [실행별 원본](commands.json)의 `context` 항목을 확인하세요.
