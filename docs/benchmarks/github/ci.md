# CI 오류 추출

`scripts/benchmarks/github_candidates.py`의 `ci`·`ci-facts`를 측정한 오프라인 프로토타입 실험입니다. 실제 `tools github` 하위 명령으로 구현된 기능은 아닙니다. 2026-10-07에 고정된 공개 GitHub 로그를 사용해 `gpt-6.1-sol`, high 추론, 방식별 새 세션 3회로 비교했습니다.

## 초기 후보 측정

실패 단계 로그를 읽는 직접 `gh` 처리의 평균 총 토큰은 35,999, CI 진단 추출 후보는 31,063으로 13.7% 적었습니다. 비교한 6회 모두 기준 정답과 일치했습니다.

[공유 후보 원본 JSON](candidates.json)의 `summary.ci`에 결과가 있습니다. 같은 자료에는 [리뷰 추출](reviews.md)과 [PR 증분 조회](delta.md)의 측정도 포함됩니다.

## 내부 파서 후속 측정

로그를 `rg`로 먼저 줄이는 기준과 구조화된 내부 파서 결과를 에이전트에 전달하는 방식을 각각 3회 추가 측정했습니다.

| 평균 | 직접 `gh + rg` | 내부 파서 + 에이전트 |
|---|---:|---:|
| 총 토큰 | 31,658 | 30,244 |
| 캐시 제외 입력 토큰 | 16,778 | 15,396 |

총 토큰은 4.5% 적었습니다. 추가 6회 모두 정답과 일치했고, 경계 사례 검사 21개를 통과했습니다. 내부 코드만 실행하면 정해진 CI·리뷰·증분 조회 정답을 모델 호출 없이 반환했습니다. 이 구성 요소의 모델 토큰은 0이지만 외부 에이전트 비용은 별도입니다.

```sh
python3 scripts/benchmarks/github_candidates.py ci-facts LOG_FILE
```

지원하는 Go 컴파일 정보를 추출하며, 지원하지 않는 형식은 원래 로그를 보존합니다. 측정 조건·개별 실행·파서 범위·한계는 [후속 원본 JSON](ci-internal.json)에 있습니다.
