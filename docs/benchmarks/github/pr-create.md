# github pr create

번호 기반 head 브랜치와 원격 커밋이 준비된 상태에서 PR을 생성했습니다. `tools github pr create --prefix fix --title "measure command workflow" --body-file body.md --json`과 직접 `gh api + git`를 비교합니다. 저장소·템플릿·연결 이슈·head와 base의 원격 비교를 확인하고, 한국어 본문에 `Closes #41`을 붙여 PR 1개와 기존 `bug` 라벨을 생성·적용합니다. 커밋 작성과 최초 head 푸시는 준비 과정으로 측정에서 제외합니다.

2026-10-07, `gpt-6.1-sol`, high 추론, 방식별 새 세션 3회입니다. 실제 `gh`·Git·프로덕션 CLI와 로컬 실험 API를 사용했습니다. 토큰은 캐시 입력을 포함한 에이전트 작업 전체의 값입니다.

| 평균 또는 범위 | 직접 `gh + git` | `tools` |
|---|---:|---:|
| 총 토큰 | 102,598 | 45,076 |
| 캐시 제외 입력 | 24,243 | 20,356 |
| 캐시 입력 | 77,525 | 24,491 |
| 출력 토큰 | 830 | 229 |
| 쉘 명령 항목 | 12.67 | 3 |
| 실행 시간(초) | 36.21 | 15.18 |
| 총 토큰 범위 | 96,770–114,042 | 45,074–45,078 |

총 토큰 차이는 −56.1%, 캐시 제외 입력은 16.0% 적었습니다. 비교한 6회 모두 반환 JSON과 독립적인 최종 상태 검증을 통과했습니다. 제목·본문·라벨·base·head·non-draft 상태와 중복 생성 없음을 확인했고 Git 참조·설정·worktree·작성 파일을 보존했습니다.

최초 `tools` 3회도 실제 PR 상태는 맞았으나, 결과 정규화 안내가 모호해 최종 JSON 제목에서 `fix:`가 빠졌습니다. 최초 PR 6회를 원본에 보존하고 비교에서 제외했습니다. 반환 제목에 접두사가 포함됨을 명시하고 양쪽을 각각 3회 다시 실행했습니다. 직접 처리에는 `python3` 명령 이름도 명시했습니다. 템플릿·리뷰어·포크 PR·실제 GitHub 서버 검증은 포함하지 않습니다.
